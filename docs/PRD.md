# PRD — Mini GTD UA

## Що це

Простий персональний менеджер задач, українською мовою, за
методологією GTD (Getting Things Done). Доступ — через вхід із
Google; кожен акаунт бачить лише свої задачі (розмежування даних
між користувачами — на рівні бази даних, через Row Level Security).
Спільної роботи над задачами немає — це особистий інструмент, не
командний.

## Функції

### Вхід через Google

Застосунок доступний лише авторизованим користувачам. Неавторизований
відвідувач бачить сторінку логіну й не може відкрити жодного зі
списків, поки не увійде.

### 5 списків задач

- **Вхідні** — куди потрапляють нові задачі за замовчуванням
- **Задачі** — задачі, готові до виконання
- **Читати/Дивитись** — матеріали для ознайомлення, не дії
- **Колись** — ідеї та задачі без дедлайну і поточного пріоритету
- **Архів** — завершені або більше не актуальні задачі

### Задача

Кожна задача має:

- назву
- нотатку
- теги
- дату
- статус

### Підзадачі (Next Actions)

Задачу можна розбити на конкретні кроки — короткий список підзадач
усередині неї, кожна з власною назвою та статусом виконання.

### Матеріали

До задачі можна прикріпити пов'язані матеріали: посилання, файли,
Notion- чи Google Drive-документи.

### Переміщення задач між списками

Задачу можна перенести з одного списку в інший (наприклад, із
«Вхідних» у «Задачі» чи «Архів»).

### Кошик (м'яке видалення)

Видалення задачі не стирає її одразу — вона потрапляє в кошик і
може бути відновлена. Остаточне видалення — окрема дія.

## Поза скоупом

Наступне свідомо не робимо в цій версії:

- **Командна робота** — без спільних задач, ролей, запрошень.
- **Складний календар** — без календарної сітки, повторюваних
  подій, нагадувань за розкладом.
- **Email-повідомлення** — без листів, дайджестів чи сповіщень
  на пошту.
